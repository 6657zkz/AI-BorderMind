# 研发路线图

> 本文是研发阶段顺序、范围和验收门槛的唯一来源。`planned` 不等于已实现；当前实现范围以 [current-state.md](current-state.md) 为准。

## 阶段 1：规划契约

**状态：部分完成。**

### 目标

建立不依赖 HTTP、数据库、LLM 或执行器的受控规划内核：业务语义图校验与唯一可执行计划编译。

### 已完成

- `CapabilityCatalog` 只读协议与决策/任务契约值对象。
- `DecisionGraph`、目录白名单校验、快照恢复。
- `ExecutionPlan`、显式输入绑定、稳定拓扑排序、依赖环检测。
- `Planned`、`NeedsClarification`、`Rejected` 规划结果。
- planning 单元测试。

### 未完成

- 真实能力目录注册表。
- 可被外部调用的最小应用服务/API 入口。
- 一个真实且完整的决策类型、任务、Operator、专家、证据与结论契约组合。

### 完成门槛

- 规划器仅接受真实能力目录中已注册且启用的决策类型。
- 至少一个决策类型具备完整任务、能力、证据和结论契约，并能通过服务层生成可审阅的 Graph/Plan。
- 未注册引用在编译前失败；缺失可补字段产生结构化澄清；依赖环不能生成计划。
- 不引入任务执行、持久化、LLM 或自由 SQL。

### 不包含

Run 状态机、数据库、调度、真实数据查询、前端、监控、text2sql。

## 阶段 2：项目、会话和受控识别

**状态：planned。依赖阶段 1 完成。**

### 目标

引入项目画像、会话和受控上下文识别，生成带快照的 `DecisionGraph`。

### 范围与门槛

- 项目、会话和消息的领域模型与应用服务边界。
- 仅从能力目录白名单中识别决策类型、范围、实体、指标和约束。
- 缺失最小前提通过结构化澄清暴露，不固化“品类 + 市场”作为通用前置条件。
- 识别/触发/上下文快照可传入 planning 编译器。

### 不包含

自由 Agent、自由 SQL、真实 Run 执行、前端工作台。

## 阶段 3：持久化与证据

**状态：planned。依赖阶段 2。需要相关 ADR。**

### 目标

为 Run、Graph、Plan、节点输入输出和证据建立持久化权威来源。

### 范围与门槛

- 数据库、仓储、迁移及可审阅 seed。
- 项目/租户隔离、权限、版本、质量和审计边界。
- Evidence 生命周期、读取、脱敏和截断规则。
- 将持久化权威来源、租户/权限和公开持久化语义记录为 ADR。

### 不包含

以 SSE 连接或内存缓存作为权威 Run/Evidence 来源。

## 阶段 4：分析运行、调度与恢复

**状态：planned。依赖阶段 3。需要执行语义 ADR。**

### 目标

实现 `AnalysisRun`/`NodeRun` 状态机和仅消费 `ExecutionPlan` 的 DAG 运行器。

### 范围与门槛

- Run/NodeRun 状态迁移、并行就绪节点、有限重试、超时、取消和恢复。
- 下游仅消费显式依赖的已验证输出与 Evidence Package。
- 用户补充字段后复用成功节点与证据，只恢复阻塞节点和下游。
- SSE 只订阅后台 Run，断开连接不取消执行。

### 不包含

API 或专家绕过 ExecutionPlan 直接执行 Operator。

## 阶段 5：监控与触发策略

**状态：planned。依赖阶段 4。**

实现原子信号、复合事件、触发策略、去重、冷却与受控创建 AnalysisRun；不直接调用 Chat 路由或执行经营动作。

## 阶段 6：前端工作台

**状态：planned。依赖阶段 4，监控视功能而定。**

按用户工作流展示会话、澄清、DecisionGraph、ExecutionPlan、节点状态、结论和证据；不按固定决策类型或节点数量硬编码流程。

## 阶段 7：受控查询规划

**状态：planned。依赖 Operator、Ontology、权限和审计边界成熟。需要数据访问 ADR。**

仅在固定 Operator 无法覆盖的需求出现后，引入 `planning/text2sql/` 和 MetricQueryGraph 的受控编译。必须强制白名单、参数化只读执行、租户条件、资源预算和审计；自由 LLM SQL 永远关闭。

## 实施规则

- 在进入一个阶段前，先满足其依赖和上阶段门槛。
- 只在阶段出现真实职责时创建目录和模块；不预建空抽象或兼容工作流。
- 模块接口/边界变化更新 [contracts/](contracts/README.md)；不可逆决定更新 [adr/](adr/README.md)；已实现范围更新 [current-state.md](current-state.md)。
